fpp3 9.11, Ex11

Choose one of the following seasonal time series: the Australian production of electricity, cement, or gas (from aus_production).

  1. Do the data need transforming? If so, find a suitable transformation.
aus_production |>
  autoplot(Electricity)

Yes, these need transforming, as the seasonal variation increases with the level of the series.

lambda <- aus_production |>
  features(Electricity, guerrero) |>
  pull(lambda_guerrero)
aus_production |>
  autoplot(box_cox(Electricity, lambda))

The Guerrero method suggests using a Box-Cox transformation with parameter \lambda = 0.52.

  1. Are the data stationary? If not, find an appropriate differencing which yields stationary data.

The trend and seasonality show that the data are not stationary.

aus_production |>
  gg_tsdisplay(
    box_cox(Electricity, lambda) |> difference(4),
    plot_type = "partial"
  )
aus_production |>
  gg_tsdisplay(
    box_cox(Electricity, lambda) |> difference(4) |> difference(1),
    plot_type = "partial"
  )
  • The seasonally differenced data still wander a little, although we could have continued with only taking seasonal differences (you may try this option).
  • We take a first order difference as well.
  1. Identify a couple of ARIMA models that might be useful in describing the time series. Which of your models is the best according to their AIC values?

fpp3 9.11, Ex12

For the same time series you used in the previous exercise, try using a non-seasonal model applied to the seasonally adjusted data obtained from STL. Compare the forecasts with those obtained in the previous exercise. Which do you think is the best approach?

lambda <- aus_production |>
  features(Electricity, guerrero) |>
  pull(lambda_guerrero)
stlarima <- decomposition_model(
  STL(box_cox(Electricity, lambda)),
  ARIMA(season_adjust)
)
fc <- aus_production |>
  model(
    ets = ETS(Electricity),
    arima = ARIMA(box_cox(Electricity, lambda)),
    stlarima = stlarima
  ) |>
  forecast(h = "2 years")
fc |> autoplot(aus_production |> filter(year(Quarter) > 2000), level = 95)

The STL-ARIMA approach has higher point forecasts (except in the first two quarters). Its prediction intervals are narrower than those from ETS, but are only narrower than those from ARIMA for the first two quarters. To decide which approach is best, we compare them on a test set consisting of the last two years of data.

train <- aus_production |>
  filter(Quarter <= max(Quarter) - 8)
fc <- train |>
  model(
    ets = ETS(Electricity),
    arima = ARIMA(box_cox(Electricity, lambda)),
    stlarima = stlarima
  ) |>
  forecast(h = "2 years")
fc |>
  accuracy(
    aus_production,
    list(RMSE = RMSE, MAE = MAE, MAPE = MAPE, winkler = winkler_score),
    level = 95
  )
# A tibble: 3 × 6
  .model   .type  RMSE   MAE  MAPE winkler
  <chr>    <chr> <dbl> <dbl> <dbl>   <dbl>
1 arima    Test  2550. 2398.  4.04  25547.
2 ets      Test  1978. 1653.  2.76  14472.
3 stlarima Test  2854. 2644.  4.46  32339.

On this test set, ETS is best on all measures, followed by the seasonal ARIMA model, with the STL-ARIMA approach the worst. The Winkler scores show that the narrower prediction intervals from the ARIMA and STL-ARIMA models are too narrow, rather than more precise. One test set of eight quarters is not much evidence, but I would use the ETS model here.

For the Australian tourism data (from tourism):

  1. Fit ARIMA models for each time series.
  2. Produce forecasts of your fitted models.
  3. Check the forecasts for the “Snowy Mountains” and “Melbourne” regions. Do they look reasonable?
fit <- tourism |>
  model(arima = ARIMA(Trips))

fc |>
  filter(Region == "Snowy Mountains") |>
  autoplot(tourism)
fc |>
  filter(Region == "Melbourne") |>

Both sets of forecasts appear to have captured the underlying trend and seasonality effectively. All four Melbourne series have increased in recent years, and their forecasts continue the upward trends. One problem is that the lower prediction interval limits for business and other travel to the Snowy Mountains are negative, which is impossible; a log transformation would avoid this.

fpp3 9.11, Ex15

Consider the number of Snowshoe Hare furs traded by the Hudson Bay Company between 1845 and 1935 (data set pelt).

  1. Produce a time plot of the time series.
pelt |>
  autoplot(Hare)
  1. Assume you decide to fit the following model: y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \phi_3 y_{t-3} + \phi_4 y_{t-4} + \varepsilon_t, where \varepsilon_t is a white noise series. What sort of ARIMA model is this (i.e., what are p, d, and q)?
  • This is an ARIMA(4,0,0), hence p = 4, d = 0 and q = 0.
  1. By examining the ACF and PACF of the data, explain why this model is appropriate.
pelt |> gg_tsdisplay(Hare, plot_type = "partial")
fit <- pelt |> model(AR4 = ARIMA(Hare ~ pdq(4, 0, 0)))
fit |> gg_tsresiduals()
  • The PACF has significant spikes at lags 1, 2 and 4 (and almost at lag 3), and no significant partial autocorrelations after lag 4, which indicates an AR(4).
  • The ACF shows a damped sinusoidal pattern, consistent with an AR model.
  • The residuals from this model look like white noise.
  1. The last five values of the series are given below:
Year 1931 1932 1933 1934 1935
Number of hare pelts 19520 82110 89760 81660 15760

The estimated parameters are c = 30993, \phi_1 = 0.82, \phi_2 = -0.29, \phi_3 = -0.01, and \phi_4 = -0.22. Without using the forecast() function, calculate forecasts for the next three years (1936–1939).

\begin{align*} \hat{y}_{T+1|T} & = 30993 + 0.82* 15760 -0.29* 81660 -0.01* 89760 -0.22* 82110 = 2051.57 \\ \hat{y}_{T+2|T} & = 30993 + 0.82* 2051.57 -0.29* 15760 -0.01* 81660 -0.22* 89760 = 8223.14 \\ \hat{y}_{T+3|T} & = 30993 + 0.82* 8223.14 -0.29* 2051.57 -0.01* 15760 -0.22* 81660 = 19387.96 \\ \end{align*}

  1. Now fit the model in R and obtain the forecasts using forecast(). How are they different from yours? Why?

fpp3 9.11, Ex16

The population of Switzerland from 1960 to 2017 is in data set global_economy.

  1. Produce a time plot of the data.
swiss_pop <- global_economy |>
  filter(Country == "Switzerland") |>
  select(Year, Population) |>
  mutate(Population = Population / 1e6)

autoplot(swiss_pop, Population)
  1. You decide to fit the following model to the series: y_t = c + y_{t-1} + \phi_1 (y_{t-1} - y_{t-2}) + \phi_2 (y_{t-2} - y_{t-3}) + \phi_3( y_{t-3} - y_{t-4}) + \varepsilon_t where y_t is the Population in year t and \varepsilon_t is a white noise series. What sort of ARIMA model is this (i.e., what are p, d, and q)?

This is an ARIMA(3,1,0), hence p = 3, d = 1 and q = 0.

  1. Explain why this model was chosen using the ACF and PACF of the differenced series.
swiss_pop |> gg_tsdisplay(Population, plot_type = "partial")
swiss_pop |> gg_tsdisplay(difference(Population), plot_type = "partial")

The original series is clearly non-stationary (with a slowly decaying ACF), so it needs differencing. For the differenced series, the last significant spike in the PACF is at lag 3, and the ACF decays in a damped sinusoidal pattern, which signals an AR(3) for the differenced series.

  1. The last five values of the series are given below.
Year 2013 2014 2015 2016 2017
Population (millions) 8.09 8.19 8.28 8.37 8.47

The estimated parameters are c = 0.0053, \phi_1 = 1.64, \phi_2 = -1.17, and \phi_3 = 0.45. Without using the forecast() function, calculate forecasts for the next three years (2018–2020).

\begin{align*} \hat{y}_{T+1|T} & = 0.0053 + 8.47+ 1.64* (8.47 - 8.37) -1.17* (8.37 - 8.28) + 0.45* (8.28 - 8.19) = 8.56 \\ \hat{y}_{T+2|T} & = 0.0053 + 8.56+ 1.64* (8.56 - 8.47) -1.17* (8.47 - 8.37) + 0.45* (8.37 - 8.28) = 8.65 \\ \hat{y}_{T+3|T} & = 0.0053 + 8.65+ 1.64* (8.65 - 8.56) -1.17* (8.56 - 8.47) + 0.45* (8.47 - 8.37) = 8.73 \\ \end{align*}
